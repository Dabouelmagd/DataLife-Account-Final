# 1. مقدمة عن النظام

## ما هو DataLife Account؟
نظام DataLife Account هو نظام متكامل لإدارة موارد المؤسسات (ERP) يعمل عبر الإنترنت، صُمم خصيصاً للشركات العربية. يدعم النظام اللغتين العربية والإنجليزية ويشمل إدارة الموارد البشرية، الإدارة المالية، الفواتير، المشتريات، المشاريع، والتقارير.

## الأدوار الوظيفية في النظام
| الدور | الصلاحيات |
|-------|----------|
| **رئيس مجلس الإدارة / المدير العام** | وصول كامل لجميع الوحدات |
| **المدير المالي / رئيس الحسابات** | الإدارة المالية، الفواتير، التقارير |
| **مدير الموارد البشرية** | الموارد البشرية، الموافقات، التقارير |
| **محاسب** | الإدارة المالية، الفواتير |
| **موظف** | لوحة التحكم والتقارير فقط |

## متطلبات التشغيل
- متصفح حديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت
- رابط النظام: **https://datalifeaccount.com**

# 2. تسجيل الدخول وإنشاء الحساب

## 2.1 تسجيل شركة جديدة
1. افتح الرابط **https://datalifeaccount.com**
2. اضغط على **"تسجيل شركة جديدة"** (Register Company)
3. أدخل البيانات المطلوبة:
   - اسم الشركة
   - البريد الإلكتروني للمسؤول
   - كلمة المرور (8 أحرف على الأقل)
   - رقم الهاتف
4. اضغط **"إنشاء حساب"**
5. سيظهر لك **كود الاشتراك** — احفظه فوراً لأنك ستحتاجه لإدارة حسابك

## 2.2 تسجيل الدخول
1. افتح **https://datalifeaccount.com/login**
2. أدخل البريد الإلكتروني وكلمة المرور
3. اضغط **"تسجيل الدخول"**
4. عند أول دخول سيظهر كود الاشتراك — اضغط **"متابعة إلى التطبيق"**

## 2.3 نسيت كلمة المرور
1. من صفحة تسجيل الدخول، اضغط **"نسيت كلمة المرور؟"**
2. أدخل بريدك الإلكتروني
3. ستصلك رسالة بها رابط لإعادة تعيين كلمة المرور

## 2.4 تغيير اللغة
- في أسفل الشريط الجانبي، اضغط على **"EN"** للإنجليزية أو **"عربي"** للعربية
- يتم تغيير واجهة النظام بالكامل فوراً

# 3. لوحة التحكم الرئيسية (Dashboard)

عند تسجيل الدخول، تظهر لوحة التحكم التي تعرض ملخصاً شاملاً لأداء الشركة.

## 3.1 البطاقات الإحصائية (الشريط العلوي)
| البطاقة | الوصف |
|---------|-------|
| **الموظفين** | إجمالي عدد الموظفين المسجلين |
| **الإيرادات** | إجمالي الإيرادات بالجنيه المصري |
| **الفواتير** | عدد الفواتير المُنشأة |
| **المنتجات** | عدد المنتجات المسجلة |

## 3.2 الإجراءات السريعة (Quick Actions)
أزرار للوصول السريع:
- **إضافة موظف** — ينتقل مباشرة لنموذج إضافة موظف جديد
- **قيد جديد** — لإنشاء قيد يومي جديد
- **فاتورة جديدة** — لإنشاء فاتورة
- **التقارير** — للانتقال لصفحة التقارير

## 3.3 النشاط الأخير
يعرض آخر العمليات التي تمت في النظام مع التصنيف (HR / مالي)

## 3.4 المهام القادمة
يعرض المهام المستحقة مع المواعيد الزمنية

## 3.5 الشريط الجانبي (Sidebar)
القائمة الرئيسية للتنقل بين وحدات النظام. كل وحدة تظهر حسب صلاحيات المستخدم.

# 4. الموارد البشرية (HR)

اضغط على **"الموارد البشرية"** في الشريط الجانبي لعرض القائمة الفرعية.

## 4.1 نظرة عامة (Overview)
صفحة رئيسية تعرض:
- إجمالي الموظفين
- إجمالي البدلات
- إجمالي الخصومات
- نسبة الحضور
- قائمة الموظفين مع الأقسام والحالة
- أزرار سريعة (إضافة موظف، كشف الرواتب، الحضور، التقارير)

## 4.2 كشف المرتبات (Payroll)
### عرض كشوف المرتبات
1. اضغط **"كشف المرتبات"** من القائمة الفرعية
2. تظهر كشوف المرتبات السابقة مع:
   - رقم الكشف
   - الشهر
   - عدد الموظفين
   - إجمالي الرواتب / الخصومات / صافي الرواتب
   - الحالة (مدفوع / معلق)

### إنشاء كشف مرتبات جديد
1. اضغط **"+ إنشاء كشف مرتبات"** (Create Payroll)
2. اختر الشهر
3. سيحسب النظام تلقائياً الرواتب والبدلات والخصومات
4. راجع البيانات ثم اضغط **"حفظ"**

### التبويبات الفرعية
| التبويب | الوصف |
|---------|-------|
| **كشوف المرتبات** | عرض وإنشاء كشوف الرواتب |
| **القروض** | إدارة قروض الموظفين |
| **نهاية الخدمة** | حساب مستحقات نهاية الخدمة |
| **التقارير** | تقارير الرواتب |
| **الإعدادات** | إعدادات الرواتب والضرائب |

## 4.3 الرواتب (Salaries)
### عرض رواتب الشهر
1. اضغط **"الرواتب"**
2. اختر الشهر من أعلى الصفحة
3. تظهر قائمة بجميع الموظفين مع:
   - الاسم والوظيفة
   - الراتب الأساسي
   - البدلات
   - الخصومات
   - صافي الراتب
   - الحالة (مدفوع / معلق)

### صرف الرواتب
1. اضغط **"صرف الرواتب"** (Process Payroll)
2. سيتم تحديث حالة جميع الرواتب إلى "مدفوع"

### تصدير البيانات
- اضغط **"تصدير"** (Export) لتحميل ملف CSV بالرواتب

## 4.4 البدلات (Allowances)
### إضافة بدل جديد
1. اضغط **"البدلات"** ثم **"+ إضافة بدل"**
2. أدخل:
   - اسم البدل (مثال: بدل مواصلات، بدل سكن)
   - المبلغ
   - النوع (شهري / مرة واحدة)
   - الموظف المستفيد
3. اضغط **"حفظ"**

### تعديل أو حذف بدل
- اضغط على أيقونة التعديل أو الحذف بجانب البدل

## 4.5 الخصومات (Deductions)
### إضافة خصم جديد
1. اضغط **"الخصومات"** ثم **"+ إضافة خصم"**
2. أدخل:
   - اسم الخصم (مثال: تأمينات اجتماعية، ضريبة دخل، سلفة)
   - المبلغ أو النسبة
   - الموظف
3. اضغط **"حفظ"**

## 4.6 الحضور (Attendance)
### تسجيل الحضور اليومي
1. اضغط **"الحضور"**
2. اختر التاريخ
3. لكل موظف، سجّل:
   - وقت الحضور
   - وقت الانصراف
   - الحالة (حاضر / غائب / إجازة / مأمورية)
4. اضغط **"حفظ"**

### تقارير الحضور
- عرض الحضور الشهري لكل موظف
- نسبة الحضور والغياب
- ساعات العمل الإضافية

## 4.7 الورديات (Shifts)
### إنشاء وردية جديدة
1. اضغط **"الورديات"** ثم **"+ إضافة وردية"**
2. أدخل:
   - اسم الوردية (صباحي / مسائي / ليلي)
   - وقت البداية والنهاية
   - أيام العمل
3. اضغط **"حفظ"**

### تعيين الورديات للموظفين
- اختر الموظف ثم حدد الوردية المناسبة

## 4.8 الإجازات العارضة (Casual Leave)
### طلب إجازة عارضة
1. اضغط **"الإجازات العارضة"** ثم **"+ طلب إجازة"**
2. أدخل:
   - الموظف
   - تاريخ البداية والنهاية
   - السبب
3. اضغط **"إرسال"**

## 4.9 الإجازات السنوية (Annual Leave)
### إدارة رصيد الإجازات
- عرض رصيد الإجازات المتبقي لكل موظف
- طلب إجازة سنوية بنفس خطوات الإجازة العارضة
- الموافقة على طلبات الإجازات من قبل المدير

## 4.10 إنهاء الخدمة (Termination)
### إنهاء خدمة موظف
1. اضغط **"إنهاء الخدمة"** ثم **"+ إنهاء خدمة"**
2. أدخل:
   - الموظف
   - تاريخ الإنهاء
   - سبب الإنهاء
   - نوع الإنهاء (استقالة / فصل / تقاعد)
3. سيحسب النظام مستحقات نهاية الخدمة تلقائياً
4. اضغط **"تأكيد"**

## 4.11 تقارير الموارد البشرية (Reports)
تقارير شاملة تشمل:
- تقرير الرواتب الشهري
- تقرير الحضور والغياب
- تقرير البدلات والخصومات
- تقرير الإجازات
- تقرير إنهاء الخدمة
- إمكانية التصفية حسب الموظف، الشهر، القسم

## 4.12 إعدادات الموارد البشرية (Settings)
- إعدادات الرواتب (ساعات العمل، أيام العمل)
- إعدادات الضرائب والتأمينات
- إعدادات الإجازات (الرصيد السنوي)
- إعدادات الورديات الافتراضية

# 5. الإدارة المالية

اضغط على **"الإدارة المالية"** في الشريط الجانبي.

## 5.1 نظرة عامة (Overview)
ملخص مالي يعرض:
- إجمالي الإيرادات والمصروفات
- صافي الربح
- رسوم بيانية للأداء المالي

## 5.2 القيود اليومية (Journal Entries)
### إنشاء قيد يومي
1. اضغط **"القيود اليومية"** ثم **"+ قيد جديد"**
2. أدخل:
   - التاريخ
   - الوصف
   - سطور القيد (حساب مدين / حساب دائن / المبلغ)
3. تأكد أن إجمالي المدين = إجمالي الدائن
4. اضغط **"حفظ"**

### البحث والتصفية
- البحث بالتاريخ أو الوصف أو رقم القيد

## 5.3 دفتر الأستاذ (General Ledger)
- عرض جميع الحركات المالية مرتبة حسب الحساب
- تصفية حسب الفترة الزمنية
- عرض الرصيد الافتتاحي والختامي لكل حساب

## 5.4 العملاء والموردين (Parties)
### إضافة عميل أو مورد
1. اضغط **"العملاء والموردين"** ثم **"+ إضافة"**
2. اختر النوع (عميل / مورد)
3. أدخل: الاسم، الهاتف، البريد، العنوان، الرقم الضريبي
4. اضغط **"حفظ"**

## 5.5 المنتجات (Products)
### إضافة منتج
1. اضغط **"المنتجات"** ثم **"+ إضافة منتج"**
2. أدخل: اسم المنتج، الكود، الوحدة، سعر البيع، سعر الشراء
3. اضغط **"حفظ"**

## 5.6 العملات (Currencies)
- إدارة العملات المستخدمة في النظام
- تحديد سعر الصرف

## 5.7 المخزون (Inventory)
- متابعة أرصدة المنتجات
- حركات الوارد والمنصرف
- تنبيهات نفاد المخزون

## 5.8 البنوك (Banks)
### إضافة حساب بنكي
1. اضغط **"البنوك"** ثم **"+ إضافة حساب"**
2. أدخل: اسم البنك، رقم الحساب، العملة، الرصيد الافتتاحي
3. اضغط **"حفظ"**

### تسجيل معاملة بنكية
1. اختر الحساب البنكي
2. اضغط **"+ معاملة جديدة"**
3. أدخل: النوع (إيداع/سحب)، المبلغ، الوصف، التاريخ
4. اضغط **"حفظ"**

## 5.9 التقارير المالية
| التقرير | الوصف |
|---------|-------|
| **ميزان المراجعة** | يعرض أرصدة جميع الحسابات |
| **قائمة الدخل** | الإيرادات والمصروفات وصافي الربح |
| **الميزانية العمومية** | الأصول والالتزامات وحقوق الملكية |
| **التقارير المالية** | تقارير مخصصة بفلاتر متعددة |

# 6. الفواتير

اضغط على **"الفواتير"** في الشريط الجانبي.

## 6.1 إنشاء فاتورة جديدة
1. اضغط **"+ فاتورة جديدة"**
2. أدخل:
   - العميل (اختر من القائمة)
   - تاريخ الفاتورة وتاريخ الاستحقاق
   - بنود الفاتورة (المنتج، الكمية، السعر)
   - الضريبة والخصم إن وجد
3. راجع الإجمالي
4. اضغط **"حفظ"** أو **"حفظ وطباعة"**

## 6.2 إدارة الفواتير
- البحث والتصفية حسب (العميل، التاريخ، الحالة)
- تعديل فاتورة قائمة
- تغيير حالة الفاتورة (مسودة / مُرسلة / مدفوعة / ملغاة)
- تحميل PDF أو طباعة

## 6.3 إعدادات ETA (الفاتورة الإلكترونية)
- ربط النظام بمنظومة الفاتورة الإلكترونية المصرية
- إدخال بيانات التسجيل الضريبي

## أنواع البيانات القابلة للاستيراد

# 12. الإعدادات

اضغط على أيقونة الإعدادات في أسفل الشريط الجانبي، أو انتقل إلى **/settings**

## 12.1 تبويب الشركة (Company)
- تعديل اسم الشركة ومعلومات التواصل
- رفع شعار الشركة (مع إمكانية قص الصورة)
- الرقم الضريبي والسجل التجاري

## 12.2 تبويب الملف الشخصي (Profile)
- عرض بيانات المستخدم (الاسم، البريد، الدور)
- **رفع الصورة الشخصية**: مرر الماوس على الصورة → اختر ملف → اقطع الصورة بالشكل المطلوب → اضغط حفظ
- **كود الاشتراك**: يُعرض هنا — احفظه في مكان آمن
- **تغيير كلمة المرور**: اضغط "تغيير" → أدخل كلمة المرور الحالية والجديدة
- **الصلاحيات**: عرض جميع الصلاحيات (21 صلاحية) الممنوحة لك

## 12.3 تبويب الموظفين (Employees)
*متاح لرئيس مجلس الإدارة والمديرين فقط*
- عرض قائمة موظفي الشركة
- دعوة موظف جديد عبر البريد الإلكتروني
- تعديل بيانات الموظفين

## 12.4 تبويب الصلاحيات (Permissions)
*متاح لرئيس مجلس الإدارة والمديرين فقط*

### تعيين صلاحيات موظف
1. اضغط على اسم الموظف لعرض صلاحياته
2. فعّل أو ألغِ الصلاحيات المطلوبة بالنقر على كل صلاحية
3. أو استخدم **"قوالب جاهزة"** لتطبيق صلاحيات دور محدد:
   - **مدير النظام**: جميع الصلاحيات (21/21)
   - **المدير المالي**: المالية، الفواتير، التقارير
   - **محاسب**: المالية، الفواتير
   - **مدير الموارد البشرية**: HR إداري ومالي
   - **مشاهد فقط**: لوحة التحكم والتقارير
4. اضغط **"تحديد الكل"** أو **"إلغاء تحديد الكل"** للتحكم السريع
5. اضغط **"حفظ"**

# 14. الأسئلة الشائعة

## كيف أضيف موظف جديد؟
اذهب إلى **الإعدادات** → **الموظفين** → **"+ دعوة موظف"** → أدخل الاسم والبريد والدور → **"إرسال الدعوة"**

## كيف أغير صلاحيات موظف؟
اذهب إلى **الإعدادات** → **الصلاحيات** → اضغط على اسم الموظف → فعّل/ألغِ الصلاحيات → **"حفظ"**

## كيف أرفع شعار الشركة؟
اذهب إلى **الإعدادات** → **الشركة** → اضغط على منطقة الشعار → اختر الملف → **"حفظ"**

## كيف أرفع صورتي الشخصية؟
اذهب إلى **الإعدادات** → **الملف الشخصي** → مرر الماوس على الصورة → اختر ملف → اقطع الصورة → **"حفظ"**

## كيف أفعّل كود التفعيل؟
اذهب إلى **صفحة الدفع** (/payment) → اختر **"كود تفعيل"** → أدخل الكود → **"تفعيل"**
(كود التفعيل = اشتراك مجاني، المبلغ = 0)

## كيف أستخدم النظام على الهاتف؟
النظام يعمل على أي متصفح بالهاتف. افتح **datalifeaccount.com** وسجل الدخول.

## كيف أحصل على إشعارات؟
عند أول دخول، سيطلب منك المتصفح السماح بالإشعارات. اضغط **"سماح"** لتفعيل إشعارات Push.
أو اضغط على أيقونة الجرس ثم **"تفعيل"**.

## نسيت كود الاشتراك، ماذا أفعل؟
اذهب إلى **الإعدادات** → **الملف الشخصي** — الكود يظهر في بطاقة "كود الاشتراك"

## كيف أتواصل مع الدعم الفني؟
البريد: **info@datalifeai.com**
