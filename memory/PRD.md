**آخر تحديث:** 5 أبريل 2026

## 📋 نظرة عامة

### وصف المشروع
نظام ERP متكامل متعدد المستأجرين (Multi-tenant) لإدارة الأعمال يدعم:
- إدارة المستخدمين والصلاحيات
- الموارد البشرية والرواتب
- المحاسبة والإدارة المالية
- المخزون والمنتجات
- الفواتير الإلكترونية
- استيراد/تصدير البيانات
- التقارير والتحليلات
- إدارة البنوك والخزينة

### التقنيات المستخدمة
| المكون | التقنية |
|--------|---------|
| Frontend | React 18 + Tailwind CSS + Shadcn/UI |
| Backend | FastAPI (Python) |
| Database | MongoDB |
| Charts | Recharts |
| Email | Resend API |
| Auth | JWT Tokens |

### المستخدمون المستهدفون
1. **مدير الشركة (Company Administrator)** - صلاحيات كاملة
2. **المدير المالي (Financial Manager)** - المحاسبة والفواتير
3. **مدير الموارد البشرية (HR Manager)** - الموظفين والرواتب
4. **مدير القسم (Department Manager)** - صلاحيات محدودة

## ✅ الميزات المنجزة

### 1. نظام المصادقة وإدارة المستخدمين
- تسجيل الدخول بـ JWT
- تسجيل شركات متعددة (Multi-tenant)
- أدوار وصلاحيات متعددة
- رفع صورة الملف الشخصي
- تغيير كلمة المرور
- حذف الموظفين (للمدير فقط)

### 2. نظام استيراد البيانات
- استيراد ملفات Excel/CSV لجميع الوحدات
- سجل الاستيرادات
- تصدير الصفوف الفاشلة
- دليل تنسيق الملفات

### 3. النظام المحاسبي المتكامل

#### 3.1 دليل الحسابات المصري (Chart of Accounts)
- **71 حساب** وفق المعايير المصرية
- هيكل هرمي (حسابات رئيسية وفرعية)
- أكواد قياسية: 1, 11, 111, 11101, etc.
- تصنيفات: أصول، خصوم، حقوق ملكية، إيرادات، مصروفات

| الكود | الحساب | النوع |
|-------|--------|-------|
| 1 | الأصول | رئيسي |
| 11 | الأصول الثابتة | رئيسي |
| 111 | الأراضي | فرعي |
| 131 | العملاء | فرعي |
| 162 | النقدية بالبنوك | فرعي |
| 251 | الموردون | فرعي |
| 331 | رواتب وأجور | فرعي |
| 411 | إيرادات مبيعات | فرعي |

#### 3.2 القيود اليومية (Journal Entries)
- إنشاء قيود يدوية
- ترحيل القيود (Post)
- عكس القيود (Reverse)
- ربط القيود بالحركات البنكية تلقائياً
- أزرار سريعة (مقبوضات، مدفوعات)

#### 3.3 التقارير المالية
- **ميزان المراجعة (Trial Balance)**
- **قائمة الدخل (Income Statement)**
- **الميزانية العمومية (Balance Sheet)**
- **دفتر الأستاذ (General Ledger)**
- تصدير Excel لجميع التقارير

### 4. نظام الفوترة الإلكترونية

#### 4.1 أنواع المستندات
- فواتير مبيعات
- فواتير مشتريات
- عروض أسعار
- أوامر شراء

#### 4.2 الميزات
- إدارة العملاء والموردين
- كتالوج المنتجات/الخدمات
- حساب ضريبة القيمة المضافة (14%)
- خصومات على مستوى البند
- إنشاء PDF مع QR Code
- إنشاء قيد محاسبي تلقائي عند الاعتماد
- تحويل عرض الأسعار لفاتورة
- تتبع المدفوعات

#### 4.3 التقارير
- تقرير المبيعات
- تقرير المشتريات
- تقرير ضريبة القيمة المضافة
- تقرير أعمار الديون (Aging Report)

### 5. دعم العملات المتعددة
- **11 عملة مدعومة:** EGP, USD, EUR, SAR, AED, GBP, KWD, QAR, BHD, OMR, JOD
- تفعيل/تعطيل العملات لكل شركة
- أسعار الصرف مع تاريخ السريان
- محول العملات
- اختيار العملة في الفواتير

### 6. الخصومات والإضافات على الفواتير
- **أنواع الخصم:** تعاقد، دفع مبكر، كمية، ترويجي، مخصص
- **أنواع الإضافات:** شحن، تركيب، تأمين، ضمان ممتد، مخصص
- نسبة أو قيمة ثابتة
- حساب تلقائي للإجمالي

### 7. إدارة الموارد البشرية

#### 7.1 إدارة الموظفين
- بيانات الموظف الكاملة
- الوظائف والأقسام
- العقود وتواريخ الانتهاء
- المؤهلات والخبرات

#### 7.2 نظام الحضور والانصراف
- تسجيل الدخول/الخروج
- ربط بأجهزة البصمة
- حساب ساعات العمل تلقائياً
- حساب التأخير والأوفرتايم
- ملخص يومي وشهري

#### 7.3 نظام الإجازات
- طلبات الإجازات
- الموافقات
- رصيد الإجازات
- أنواع متعددة (سنوية، مرضية، طارئة)

#### 7.4 نظام الرواتب
- حساب الراتب التلقائي
- البدلات والاستقطاعات
- كشوف الرواتب
- تصدير البيانات

### 8. إدارة البنوك والخزينة ⭐ (محدّث)

#### 8.1 إدارة الحسابات البنكية
- إضافة بنوك متعددة لكل شركة
- بيانات الحساب (IBAN, SWIFT, الفرع)
- تتبع الأرصدة

#### 8.2 الحركات البنكية
| نوع الحركة | الوصف |
|------------|-------|
| إيداع (deposit) | إيداع نقدي للبنك |
| سحب (withdrawal) | سحب نقدي من البنك |
| شيك وارد (check_deposit) | إيداع شيك من عميل |
| شيك صادر (check_issued) | صرف شيك لمورد |
| تحويل وارد (transfer_in) | تحويل من بنك آخر |
| تحويل صادر (transfer_out) | تحويل لبنك آخر |

#### 8.3 الربط بالقيود المحاسبية (جديد)
- **إنشاء قيد تلقائي** لكل حركة بنكية
- **منطق القيود:**
  | العملية | مدين | دائن |
  |---------|------|------|
  | إيداع | 162 البنك | الحساب المقابل |
  | سحب | المصروفات | 162 البنك |
  | شيك وارد | 162 البنك | 131 العملاء |
  | شيك صادر | 251 الموردون | 162 البنك |

- **اختيار الحساب المقابل:** قائمة منسدلة مع حسابات موصى بها
- **عرض القيد المرتبط:** نافذة لعرض تفاصيل القيد من جدول الحركات

#### 8.4 إعدادات البنك (جديد)
- **الترحيل التلقائي:** 
  - مفعّل: القيود تُرحّل فوراً
  - معطّل: القيود تبقى مسودة للمراجعة
- **الحسابات الافتراضية:** تحديد حساب مقابل افتراضي لكل نوع عملية
- **تنبيهات المعاملات الكبيرة:** تحديد حد المبلغ + إشعار

### 9. نظام إشعارات البريد الإلكتروني ⭐ (جديد)

#### 9.1 أنواع الإشعارات
| الإشعار | الوصف | الإعداد الافتراضي |
|---------|-------|------------------|
| معاملات بنكية كبيرة | تنبيه عند تجاوز مبلغ معين | > 100,000 ج.م |
| كشوف الرواتب | إرسال للموظفين | مفعّل |
| انتهاء العقود | قبل انتهاء العقد | 30 يوم |
| الفواتير المستحقة | قبل تاريخ الاستحقاق | 7 أيام |
| طلبات الموافقة | إشعار بطلب جديد | مفعّل |

#### 9.2 قوالب البريد
- تصميم HTML مع دعم RTL
- قوالب جاهزة:
  - تنبيه معاملة بنكية
  - كشف راتب
  - انتهاء عقد
  - فاتورة مستحقة
  - طلب موافقة

#### 9.3 إعدادات الإشعارات
- إدارة عناوين البريد الإلكتروني للإدارة
- تفعيل/تعطيل كل نوع إشعار
- إرسال بريد تجريبي
- سجل الإشعارات المرسلة

### 10. لوحة التحكم الإدارية المتقدمة ⭐ (جديد)

## 🔌 واجهات API الرئيسية

### المحاسبة
| Method | Endpoint | الوصف |
|--------|----------|-------|
| GET | /api/accounting/accounts | جلب دليل الحسابات |
| POST | /api/accounting/journal-entries | إنشاء قيد |
| POST | /api/accounting/journal-entries/{id}/post | ترحيل قيد |
| GET | /api/accounting/trial-balance | ميزان المراجعة |
| GET | /api/accounting/income-statement | قائمة الدخل |
| GET | /api/accounting/balance-sheet | الميزانية |

### البنوك
| Method | Endpoint | الوصف |
|--------|----------|-------|
| GET | /api/bank-accounts | جلب الحسابات البنكية |
| POST | /api/bank-accounts | إضافة حساب بنكي |
| POST | /api/bank-transactions | إنشاء حركة (+ قيد تلقائي) |
| GET | /api/bank-transactions/{id}/journal-entry | جلب القيد المرتبط |
| GET | /api/bank-settings | جلب إعدادات البنك |
| PUT | /api/bank-settings | تحديث الإعدادات |
| GET | /api/bank-counter-accounts | الحسابات المقابلة |

### الإشعارات
| Method | Endpoint | الوصف |
|--------|----------|-------|
| POST | /api/notifications/send-email | إرسال بريد |
| POST | /api/notifications/send-bulk-email | إرسال جماعي |
| GET | /api/notifications/settings | جلب الإعدادات |
| PUT | /api/notifications/settings | تحديث الإعدادات |
| GET | /api/notifications/logs | سجل الإشعارات |
