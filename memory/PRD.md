## 📋 نظرة عامة

### وصف المشروع
نظام ERP متكامل متعدد المستأجرين (Multi-tenant) لإدارة الأعمال يدعم:
- إدارة المستخدمين والصلاحيات
- الموارد البشرية والرواتب
- المحاسبة والإدارة المالية
- المخزون والمنتجات
- الفواتير الإلكترونية
- استيراد/تصدير البيانات
- التقارير والتحليلات
- إدارة البنوك والخزينة

### التقنيات المستخدمة
| المكون | التقنية |
|--------|---------|
| Frontend | React 18 + Tailwind CSS + Shadcn/UI |
| Backend | FastAPI (Python) |
| Database | MongoDB |
| Charts | Recharts |
| Email | Resend API |
| Auth | JWT Tokens |

### المستخدمون المستهدفون
1. **مدير الشركة (Company Administrator)** - صلاحيات كاملة
2. **المدير المالي (Financial Manager)** - المحاسبة والفواتير
3. **مدير الموارد البشرية (HR Manager)** - الموظفين والرواتب
4. **مدير القسم (Department Manager)** - صلاحيات محدودة

### 8. إدارة البنوك والخزينة ⭐ (محدّث)

#### 8.1 إدارة الحسابات البنكية
- إضافة بنوك متعددة لكل شركة
- بيانات الحساب (IBAN, SWIFT, الفرع)
- تتبع الأرصدة

#### 8.2 الحركات البنكية
| نوع الحركة | الوصف |
|------------|-------|
| إيداع (deposit) | إيداع نقدي للبنك |
| سحب (withdrawal) | سحب نقدي من البنك |
| شيك وارد (check_deposit) | إيداع شيك من عميل |
| شيك صادر (check_issued) | صرف شيك لمورد |
| تحويل وارد (transfer_in) | تحويل من بنك آخر |
| تحويل صادر (transfer_out) | تحويل لبنك آخر |

#### 8.3 الربط بالقيود المحاسبية (جديد)
- **إنشاء قيد تلقائي** لكل حركة بنكية
- **منطق القيود:**
  | العملية | مدين | دائن |
  |---------|------|------|
  | إيداع | 162 البنك | الحساب المقابل |
  | سحب | المصروفات | 162 البنك |
  | شيك وارد | 162 البنك | 131 العملاء |
  | شيك صادر | 251 الموردون | 162 البنك |

- **اختيار الحساب المقابل:** قائمة منسدلة مع حسابات موصى بها
- **عرض القيد المرتبط:** نافذة لعرض تفاصيل القيد من جدول الحركات

#### 8.4 إعدادات البنك (جديد)
- **الترحيل التلقائي:** 
  - مفعّل: القيود تُرحّل فوراً
  - معطّل: القيود تبقى مسودة للمراجعة
- **الحسابات الافتراضية:** تحديد حساب مقابل افتراضي لكل نوع عملية
- **تنبيهات المعاملات الكبيرة:** تحديد حد المبلغ + إشعار
