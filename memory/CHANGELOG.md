## [أبريل 2026] - التحديثات الأخيرة

### ✨ ميزات جديدة

#### 🏦 إدارة البنوك المتقدمة
- **الربط بالقيود المحاسبية:** كل حركة بنكية تُنشئ قيد محاسبي تلقائياً
- **إعدادات البنك:** صفحة جديدة للتحكم في:
  - الترحيل التلقائي للقيود
  - الحسابات المقابلة الافتراضية
  - تنبيهات المعاملات الكبيرة
- **عرض القيد المرتبط:** نافذة Modal لعرض تفاصيل القيد من جدول الحركات

#### 📧 نظام إشعارات البريد الإلكتروني
- **Backend API جديد:** `/api/email_notifications.py`
- **أنواع الإشعارات:**
  - معاملات بنكية كبيرة
  - كشوف رواتب الموظفين
  - انتهاء العقود
  - الفواتير المستحقة
  - طلبات الموافقة
- **قوالب HTML:** دعم RTL للعربية
- **صفحة الإعدادات:** إدارة الإيميلات + toggles + سجل الإشعارات

#### 📊 لوحة التحكم الإدارية المتقدمة
- **صفحة جديدة:** `AdminDashboardPage.jsx`
- **8 بطاقات إحصائية:** إيرادات، رصيد البنوك، فواتير، ربح، موظفين، عملاء، منتجات، مشاريع
- **رسوم بيانية تفاعلية:**
  - Revenue & Expenses (6 أشهر)
  - Expenses Breakdown (Pie Chart)
- **قوائم:** آخر الحركات + التنبيهات

### 📊 APIs الجديدة

#### البنوك
- `GET /api/bank-counter-accounts` - الحسابات المقابلة
- `GET /api/bank-transactions/{id}/journal-entry` - القيد المرتبط
- `POST /api/bank-transactions/{id}/create-journal` - إنشاء قيد لحركة قديمة
- `GET /api/bank-settings` - إعدادات البنك
- `PUT /api/bank-settings` - تحديث الإعدادات

#### الإشعارات
- `POST /api/notifications/send-email` - إرسال بريد
- `POST /api/notifications/send-bulk-email` - إرسال جماعي
- `GET /api/notifications/settings` - جلب الإعدادات
- `PUT /api/notifications/settings` - تحديث الإعدادات
- `GET /api/notifications/logs` - سجل الإشعارات
- `POST /api/notifications/trigger/large-transaction` - تنبيه معاملة كبيرة
- `POST /api/notifications/trigger/payslips` - إرسال كشوف الرواتب
